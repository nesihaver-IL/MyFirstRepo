Structure for Jira | Data Center
Structure
Arrange Jira issues into the hierarchy your plan needs
Structure is an add-on for Jira Data Center. It arranges issues into the hierarchy your plan needs, so the plan and the work stay in one place.

We will build one plan for a security product release. The goal sits at the top, three features sit under it, and the stories that deliver each feature sit under those.

Step 2 | Add issues
Add issues by query
project = SEC AND labels = release-q1
SEC-101Ingest threat-intel feed v2
SEC-102Export case report as PDF
SEC-105Alert deduplication rule
SEC-107Map entities to case graph
SEC-103Audit log retention policy
SEC-109Release notes for v4.2
Add issues by query or by hand. A query keeps the list current as new issues appear in Jira.
Step 3 | Build the hierarchy
Drag issues under their parent
Threat-intel feed0 of 3 done
SEC-101Ingest threat-intel feed v2In progress
SEC-105Alert deduplication ruleDone
Case export1 of 2 done
SEC-102Export case report as PDFTo do

Build the tree by moving issues under their parent. Each parent shows the totals of the work beneath it.
Step 4 | Columns and formulas
Add a percent-done column
0%
Threat-intel feed
3 of 4 stories done
0%
Case export
1 of 2 stories done
Add a column that calculates a value from the Jira fields you already use. One formula is enough to start, such as percent done.
Step 5 | Generators
Keep the plan current automatically
Generator: add issues matching labels = release-q1
SEC-101Ingest threat-intel feed v2In progress
SEC-105Alert deduplication ruleDone
SEC-111New: Add SIEM connectorAdded
SEC-112New: Case timeline viewAdded
A generator adds new matching issues to the plan automatically. Set it once, and the plan keeps itself current.

Three tips
1
Start with the goal, not the tasks.
2
Check one roll-up against Jira by hand before you trust it.
3
Use Structure to plan. Use Jira to do the work.
