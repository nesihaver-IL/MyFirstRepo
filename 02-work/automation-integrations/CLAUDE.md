# CLAUDE.md - Automation Integrations

## Project Overview

Collection of JIRA and Confluence automation integrations.

## Technology Stack

- **Language**: Python 3.11+
- **APIs**: JIRA REST API, Confluence REST API
- **Automation**: AWS Lambda / Azure Functions

## Current Integrations

- JIRA ticket automation
- Confluence page sync
- Cross-platform notifications

## Development Guidelines

- Follow API rate limits
- Implement retry logic
- Log all API calls
- Handle pagination properly
