- בעיה: איך מזהים איום לפני שהוא קרה?

### סלייד 4: המוצרים המרכזיים (בהדגשה: NI ו-X)

**כותרת**: "המוצרים והפתרונות שלנו"

**המוצרים העיקריים**:

#### 1. **NEXYTE** - Decision Intelligence (בינה לקבלת החלטות)
- **מה זה?**: פלטפורמה שמאחדת כל סוגי המידע (טקסט, תמונות, וידיאו, אודיו)
- **למה חשוב?**: משפחות אדם מרגישות בטוחות יותר כי בודקים יכולים להבין ולפתור מקרים בנכונות גבוהה
- **דוגמה**: מוקד בטיחות המרכזי של עירייה משתמש ב-NEXYTE כדי לברר בדיוק מה קרה בזמן הקריאה הבטיחותית

#### 2. **Network Intelligence (NI)** - בינה רשתית
- **מה זה?**: כלי שעוקב אחר תקשורות (טלפון, אינטרנט, בדיקות)
- **כיצד עובד?**: 
  - אוספת מידע מכל מקורות התקשורה
  - מזהה דפוסים שנראים חשודים
  - מחבר בין מידע שונה כדי להבין מי מדבר עם מי ולמה
- **דוגמה**: שירות בטיחות משתמש ב-NI כדי להתריע כשיש דבר-דבר מחבל או עולם עדים בתקשורת ממנו אפילו לא שמו כללים

#### 3. **Operational Intelligence** - בינה תפעולית (אקשן)
- **מה זה?**: מערכת שנותנת מידע ישיר לשדה לשימוש בזמן אמת
- **למה?**: כדי שיחידות תחקיר בשטח יוכלו לקחת החלטות נכונות מיידית

#### 4. **Threat Intelligence** - בינה על איומים
- **מה זה?**: שירותי מזהים איומים חדשים בעולם
- **חשוב?**: מעניע סכנות לפני שהם הופכים לבעיות

**דוגמה ויזואלית**: ציור / ערכת סמלים למוצרים שונים

## חלק 2: ניהול פרויקטים בפיתוח

### סלייד 5: מה זה ניהול פרויקטים?

**כותרת**: "ניהול פרויקטים - תוכנית עבודה חכמה"

**הגדרה בפשטות**:
ניהול פרויקטים זה כמו כשאתה מעביר לחבריך בכיתה לבנות בית כרטיסים:
- אתה צריך **תוכנית** (איך נבנה?)
- **חלוקת עבודה** (מי עושה מה?)
- **אבטחת זמן** (כמה זמן לכל חלק?)
- **איכות** (הבית לא יקרוס!)

**למה חשוב בתעשיית הטכנולוגיה?**
- כשאתה בונה תוכנה (אפליקציה, אתר), יש הרבה דברים קטנים שצריכים לעבוד ביחד
- אם לא מנהלים נכון, הפרויקט עלול להיות איחור, מעל תקציב, או לא יעבוד כראוי

**4 עמודים חיוניים**:
1. **זמן** - כמה זמן לוקח?
2. **מידע** (Scope) - מה בדיוק אנחנו בונים?
3. **עובדים וכסף** (Resources) - כמה אנשים צריכים? מה התקציב?
4. **איכות** - האם זה עובד בצורה טובה?

### סלייד 6: שתי שיטות עיקריות - Agile ו-Waterfall

**כותרת**: "Agile vs Waterfall - שתי דרכים שונות"

#### **Waterfall** (מפל מים)
```
Design → Build → Test → Deploy
   ↓        ↓       ↓       ↓
  Week 1   Week 2  Week 3  Week 4
```
- אתה מתכננת הכל בתחילה
- ואז אתה בונה את הכל כמו המתכנית
- **כמו**: בניית בית - אתה מתחיל עם ציור מלא, ואז בונה

#### **Agile** (זריז/חד-רעיון)
```
Sprint 1 → Sprint 2 → Sprint 3 → Sprint 4
 (1-2 שבועות)
  Plan + Build + Test + Review → Feedback → Adjust
```
- אתה מתכננת קצת, בונה קצת, בודקת, ואז למדת
- אתה משנה את התוכנית בהתאם למה שאתה לומד
- **כמו**: משחק וידיאו - אתה בודק את הרעיון הראשון, ואז מעדכן אותו בהתאם למשחק משחקים

**מה ממשיך בכל שיטה**:
- יומי "Stand-up" - כול אחד מדווח 2 דקות: "אני עשיתי את זה, אני עושה את זה, יש לי בעיה..."
- סקירת (Review) - "הנה מה שבנינו הפעם, מה דעתכם?"
- התחשבות (Retrospective) - "מה עבד טוב? מה לא?"

**בחברה בתעשיית טכנולוגיה כמו COGNYTE**:
- הם משתמשים ב-Agile כי הם צריכים לשנות את התוכנה בתדירות מהירה
- כשלקוח אומר "אנחנו צריכים תכונה חדשה", הם יכולים להוסיף אותה במהירות

### סלייד 7: כלים וטכניקות מעשיות

**כותרת**: "כלים יומיומיים בניהול פרויקטים"

#### **1. Kanban Board (לוח ניהול)**
```
┌──────────────┬──────────────┬──────────────┐
│   TO DO      │   IN PROGRESS│    DONE      │
├──────────────┼──────────────┼──────────────┤
│ Build login  │ Code server  │ Design UI    │
│ Add database │ Test buttons │ Create DB    │
│ Fix bug #24  │              │              │
└──────────────┴──────────────┴──────────────┘
```
- **מה זה?**: לוח עם כרטיסיות של משימות
- **למה?**: כדי שכולם יראו מה בעבודה כרגע

#### **2. Gantt Chart (תרשים זמנים)**
```
משימה          |שבוע 1|שבוע 2|שבוע 3|שבוע 4|
Design          |████  |      |      |      |
Development     |      |█████████|    |      |
Testing         |      |      |████ |      |
Deployment      |      |      |     |██    |
```
- **מה זה?**: תרשים שמראה אילו משימות עושים בזמן סוג
- **למה?**: כדי שתוכל לראות אם אתה בעיכוב בזמן

#### **3. Daily Stand-up** (מפגש יומי 15 דקות)
- **על מה?**:
  - "אני עשיתי [משימה] אתמול"
  - "אני עושה [משימה] היום"
  - "יש לי [בעיה] וצריך עזרה"

#### **4. Sprint Planning** (תכנון ספרינט)
- בתחילת כל שבועיים/שבוע:
  - הצוות בוחר משימות להשלים
  - משמות אם זה אפשרי ממציא

#### **5. Retrospective** (חזרה אחורה)
- בסוף כל ספרינט:
  - "מה טוב?" ✅
  - "מה לא טוב?" ❌
  - "מה אנחנו משנים בפעם הבאה?" 🔄

### סלייד 8: ניהול פרויקטים ב-COGNYTE

**כותרת**: "איך COGNYTE משתמשת בניהול פרויקטים?"

**מבנה הצוותים ב-COGNYTE**:
```
מנהל פרויקט (Product Manager)
         ↓
    Scrum Master
    (מנהל התהליך)
         ↓
צוות פיתוח (5-10 מתכנתים + בודקים)
```

**המשימות של צוות COGNYTE**:
1. **בנייה של מוצר חדש**: Agile sprints של שבועיים
2. **תיקון באגים**: כשלקוח מדווח על בעיה, היא עולה לשימוש עדיפות
3. **שדרוג קודי**: כל מספר חודשים מוציאים גרסה חדשה עם תכונות חדשות
4. **בדיקות אבטחה**: צוות בדיקה מיוחד משחק עם המערכת כדי למצוא כל חולשות

**דוגמה: איך COGNYTE יצרה את Network Intelligence**:
- **Sprint 1-2**: "בואו נקבל מידע מטלפונים"
- **Sprint 3-4**: "בואו נזהה דפוסים חשודים"
- **Sprint 5-6**: "בואו נוסיף AI כדי לזהות סוגי איומים"
- **Sprint 7+**: "בואו נבדוק ונטבע את כל הבעיות"
- תוצאה: מערכת שלמה שמצילה חיים!

### סלייד 10: Claude Notebook LM

**כותרת**: "Claude Notebook LM - עוזר מחקר ותרגום"

**מה זה Claude?**
- AI שנבנה על ידי Anthropic (חברה של מדענים בארה"ב)
- יכול לקרוא מסמכים ארוכים (עד 200,000 מילים!)
- טוב בכתיבה, הסבור וניתוח

**יכולות**:
1. **קריאת מסמכים** - תוכל להעלות קובץ PDF / Word / TXT ו-Claude יקרא את כל זה
2. **סיכום** - "סכם את זה ב-3 משפטים"
3. **תרגום** - יכול לתרגם בין שפות
4. **כתיבה** - יכול לעזור לכתוב דוח, מסקנה, אפילו קוד
5. **שאלות** - אתה שואל שאלות על המסמך ו-Claude עונה

**יתרונות Claude על ChatGPT**:
- ✅ יודע לקרוא מסמכים ארוכים יותר (context window)
- ✅ בדרך כלל יותר מדויק
- ✅ טוב בנושאים אקדמיים

**דוגמה**: אתה צריך לכתוב דוח על היסטוריה
1. אתה מעלה PDF של ספר היסטוריה
2. אתה כותב ל-Claude: "כתוב לי דוח בן 5 עמודים על השוה"ם"
3. Claude קורא את הספר ו**כותב סיכום מעולה בשניות**!

### סלייד 11: ChatGPT

**כותרת**: "ChatGPT - השיחה שלך עם AI"

**מה זה ChatGPT?**
- AI שנבנה על ידי OpenAI (חברה שבנתה את דגם GPT)
- הרבה יותר אנשים משתמשים בו מ-Claude
- טוב בתשובה לשאלות כלליות

**יכולות**:
1. **שיחה תרגום** - יכול לדבר איתך כמו בן אדם
2. **כתיבה** - עזרה בכתיבת דברים (דוח, שיר, סרט)
3. **קידוד** - כתיבת קוד (Python, JavaScript וכו')
4. **הסברים** - הוא יכול להסביר כמעט כל דבר
5. **brainstorming** - אתה נותן רעיון והוא נותן רעיונות חדשים

**יתרונות ChatGPT על Claude**:
- ✅ יותר פופולרי, אז יותר דוגמאות באינטרנט
- ✅ יכול לעזור בקוד (מתכנתים אוהבים אותו)
- ✅ יש גרסה חינם טובה

**דוגמה**: אתה צריך להבין מתמטיקה
1. אתה שואל: "איך מחשבים שטח משולש?"
2. ChatGPT מסביר בדרך קלה
3. זה נותן דוגמה עם מספרים
4. זה מציע בעיות תרגול!

### סלייד 14: טיפים חשובים בעבודה עם AI

**כותרת**: "5 דברים שצריך לדעת"

#### **1. AI לא תמיד צודק**
- ✗ כל תשובה של AI צריכה לעבור בדיקה ממך
- ✓ בדוק תמיד את הפרטים

#### **2. צריך לשאול בצורה טובה**
- ✗ רע: "תכתוב לי דוח"
- ✓ טוב: "תכתוב לי דוח בן 5 עמודים על ניהול פרויקטים, בעברית, בדיוק מקצועי אבל פשוט"

#### **3. AI היא כמו עוזר - לא משחק שיעורים**
- ✗ מהלך רע: להעתיק בדיוק את מה ש-AI כתב
- ✓ דרך חכמה: תן ל-AI לעזור בעיצוב, ואתה כתב בשפה שלך

#### **4. לא לשתף מידע סודי**
- ✗ אל תכניסו סיסמאות, מכתבים אישיים, וכו'
