# .plans/ — Claude Code Execution Plans

## Convention
This directory contains **active implementation plans** generated by the `create-plan` skill
and consumed by the `execute-plan` skill.

**File naming**: `PLAN-{project-slug}-{YYYY-MM-DD}.md`

## What belongs here
- Claude-generated step-by-step execution plans
- Active work in progress (plans currently being executed)

## What does NOT belong here
- Strategic research → `03-plans/research/`
- Roadmaps and OKRs → `03-plans/roadmaps/`
- Project proposals → `03-plans/templates/`
- Completed/archived plans → `03-plans/archive/`
