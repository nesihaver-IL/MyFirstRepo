# Learning Resources

This folder contains educational materials about building AI agents from scratch.

## Contents

### 📚 Lessons
The `lessons/` folder contains 12 comprehensive markdown lessons covering AI agent development:

1. **01_basic_llm_chat.md** - Introduction to basic LLM chat functionality
2. **02_system_prompt.md** - Understanding and using system prompts
3. **03_structured_output.md** - Working with structured outputs
4. **04_decision_making.md** - Implementing decision-making in agents
5. **05_tools.md** - Tool integration and usage
6. **06_agent_loop.md** - Building the core agent loop
7. **07_memory.md** - Implementing memory systems
8. **08_planning.md** - Agent planning strategies
9. **09_atomic_actions.md** - Breaking down actions into atomic components
10. **10_atom_of_thought.md** - Advanced reasoning patterns
11. **11_evals.md** - Evaluation and testing methodologies
12. **12_telemetry.md** - Monitoring and telemetry

### 🖼️ Diagrams
The `diagrams/` folder contains visual diagrams to support the lessons:

- **agent-architecture.png** - Overall agent architecture overview
- **lesson-05-tool-calling.png** - Tool calling workflow
- **lesson-06-agent-loop.png** - Agent loop visualization
- **lesson-07-memory.png** - Memory system diagram
- **lesson-08-planning.png** - Planning process visualization
- **lesson-10-atom-of-thoght.png** - Atom of thought concept

## Source

These materials are from the [agents-from-scratch](https://github.com/pguso/agents-from-scratch) repository, which provides a comprehensive learning path for understanding how AI agents work from first principles.

## Usage

Start with lesson 01 and progress sequentially through the materials. Refer to the diagrams as visual aids while studying the corresponding lessons.
