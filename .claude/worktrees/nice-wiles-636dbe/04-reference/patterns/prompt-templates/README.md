# Prompt Templates

Reusable prompt templates for common tasks.

## Available Templates

### General

- `system-prompts.md` - System prompt templates
- `rag-prompts.md` - RAG-specific prompts
- `agent-prompts.md` - Agent instruction prompts

## Usage

Copy and customize templates for your specific use case.

## Best Practices

1. **Be specific**: Clear instructions produce better results
2. **Examples**: Include few-shot examples when possible
3. **Structure**: Use clear formatting (XML tags, markdown)
4. **Constraints**: Specify output format and limits
5. **Test**: Iterate based on edge cases
