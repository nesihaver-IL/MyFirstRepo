# CLAUDE.md - Plans & Strategy

## Purpose

This directory contains strategic planning documents, roadmaps, and research.

## Content Types

- **Roadmaps**: Long-term planning and goals
- **Research**: Technology evaluations and comparisons
- **Templates**: Reusable planning templates
- **Archive**: Completed plans for reference

## Planning Approach

1. Define clear objectives
2. Break down into actionable steps
3. Set measurable outcomes
4. Review and iterate regularly

## Document Standards

- Use clear, action-oriented language
- Include measurable success criteria
- Link to relevant resources
- Date all documents

## Review Schedule

- Weekly: Active task review
- Monthly: Progress assessment
- Quarterly: Roadmap updates
- Yearly: Strategic planning
