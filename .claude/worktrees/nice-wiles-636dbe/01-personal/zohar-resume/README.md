# קורות חיים של זוהר — Resume Optimization

## 📁 מבנה התיקייה

```
01-personal/zohar-resume/
├── README.md                  ← קובץ זה
├── resume-current.md          ← קורות החיים הקיימים (העתיקו את הקיימים)
├── job-target.md              ← תיאור התפקיד/המשרה המטרה
├── job-current.md             ← תיאור התפקיד הנוכחי (אופציונלי)
├── linkedin-profile.txt        ← טקסט מפרופיל LinkedIn
├── references.md              ← הערות על הישגים ורפרנסים
└── context.md                 ← קונטקסט כללי (אופציונלי)
```

---

## 📤 איך להעלות את הקבצים

### קבצים שצריך להעלות (חובה):

1. **resume-current.md** — קורות החיים הקיימים שלזוהר
   - העתיקו בדיוק כמו שהם עכשיו
   - לא צריך לשנות כלום

2. **job-target.md** — המשרה שזוהר מחפשת
   - תיאור התפקיד המטרה
   - דרישות של המשרה
   - יתרונות (preferred)

3. **linkedin-profile.txt** — פרופיל LinkedIn (או פרופיל מקצועי כלשהו)
   - כותרת
   - About / תיאור
   - ניסיון עבודה
   - כישורים

### קבצים נוספים (חשובים):

4. **references.md** — הערות על הישגים/הצלחות
   - הישגים עיקריים
   - הערות מ-מנהלים או קולגות
   - פרויקטים חשובים

---

## 🚀 מה שיקרה אחרי שתעלו את הקבצים

כשתעלו את כל הקבצים, אני אוכל להריץ את `resume-optimizer` ולקבל:

✅ **ניתוח התפקיד** — מה בדיוק צריכים לתפקיד
✅ **ניתוח התאמה** — היכן זוהר חזקה, איפה יש פערים
✅ **מחקר שוק** — מה עוד משרות דומות מצפות
✅ **שיפור כדורים** — איך לכתוב את ההישגים בצורה חזקה יותר
✅ **קורות חיים משופרים** — גרסה מותאמת למשרה הספציפית

---

## 💡 טיפים חשובים

- ✅ **לא תציאו מהציאות** — אני אעבוד עם המספרים והניסיון הקיימים
- ✅ **אם יש מספרים** — כללו אותם (משתמשים, תקציב, תוצאות)
- ✅ **תפקיד נוכחי חשוב** — עזור לי להבין מהיכן זוהר באה
- ✅ **פערים בקריירה** — אם יש, כתבו את ההסבר
