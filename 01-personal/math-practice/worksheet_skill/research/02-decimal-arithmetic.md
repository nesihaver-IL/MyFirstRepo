# מחקר: חיבור וחיסור של מספרים עשרוניים

## מטרות למידה
- לחבר ולחסר מספרים עשרוניים עד שתי ספרות אחרי הנקודה
- ליישר נקודות עשרוניות בטור
- לטפל בנשיאה/הלוואה בחיבור/חיסור

## טעויות נפוצות
1. **אי-יישור נקודות** - כותבים 3.4 + 1.25 בלי ליישר ומקבלים שגיאה.
   תיקון: תמיד ליישר את הנקודות העשרוניות זה מתחת לזה.
2. **השמטת אפסים** - בחיסור 4.3 - 2.17: לא מוסיפים אפס ל-4.3 כדי לקבל 4.30.
   תיקון: להשלים עם אפסים עד לאורך שווה: 4.30 - 2.17.
3. **הזזת הנקודה בתוצאה** - שוכחים לשים נקודה בתוצאה.

## דוגמאות

### דוגמה 1 - חיבור עשיריות
**שאלה:** 4.6 + 3.7 = ?
**פתרון:**
```
  4.6
+ 3.7
-----
  8.3
```
עשיריות: 6 + 7 = 13, כותבים 3 ונושאים 1.
שלמים: 4 + 3 + 1 = 8.
**תשובה: 8.3**

### דוגמה 2 - חיסור מאיות
**שאלה:** 5.30 - 2.47 = ?
**פתרון:**
```
  5.30
- 2.47
------
  2.83
```
מאיות: 0 < 7, נלוה: 10 - 7 = 3, נשאר 2.
עשיריות: 2 < 4 (כבר לווינו), מדבר: 12 - 4 = 8, נשאר 3...
**תשובה: 2.83**

### דוגמה 3 - בעיה מילולית
**שאלה:** דנה שתתה 0.35 ליטר מיץ ואחר כך עוד 0.6 ליטר. כמה שתתה בסך הכל?
**פתרון:** 0.35 + 0.60 = 0.95 ליטר
