# Latte Art - Heart Design

## Flow Chart: Steps to Create a Heart Latte Art

```
 START
   |
   v
+---------------------------+
|  1. Prepare Espresso      |
|  Double shot, 18g in,     |
|  36g out, 25-30 sec       |
+---------------------------+
   |
   v
+---------------------------+
|  2. Steam Milk            |
|  Full fat milk, 60-65°C   |
|  Create microfoam         |
|  (silky, no big bubbles)  |
+---------------------------+
   |
   v
+---------------------------+
|  3. Tap & Swirl           |
|  Tap jug on counter       |
|  Swirl to integrate foam  |
|  (glossy, paint-like)     |
+---------------------------+
   |
   v
+---------------------------+
|  4. Initial Pour          |
|  Hold cup at 45° angle    |
|  Pour from HIGH (~10cm)   |
|  Thin stream to center    |
|  Fill to ~1/3 of cup      |
+---------------------------+
   |
   v
+---------------------------+
|  5. Create the Heart Base |
|  LOWER jug close to       |
|  surface (~1cm)           |
|  Increase flow rate       |
|  White circle appears     |
+---------------------------+
   |
   v
+---------------------------+
|  6. Build the Heart Shape |
|  Keep pouring at center   |
|  Gentle side-to-side      |
|  wiggle to widen circle   |
|  Fill to ~3/4 of cup      |
+---------------------------+
   |
   v
+---------------------------+
|  7. Pull Through          |
|  RAISE jug slightly       |
|  Thin the stream          |
|  Pull straight through    |
|  center toward far edge   |
+---------------------------+
   |
   v
+---------------------------+
|  8. Finish                |
|  Clean cut at the end     |
|  Heart shape appears!     |
+---------------------------+
   |
   v
  DONE
```

## Pro Tips

```
+----------------------------------------------------------------+
|                        Pro Tips                                |
+----------------------------------------------------------------+
|                                                                |
|  * Milk temperature: 60-65°C - too hot kills the foam         |
|  * Microfoam texture: like wet paint, no visible bubbles       |
|  * Cup angle: 45° until half full, then gradually flatten     |
|  * Pour height controls mixing:                                |
|       HIGH = milk sinks into espresso (brown)                  |
|       LOW  = milk floats on top (white art)                    |
|  * The "pull through" creates the heart's point                |
|  * Practice with water + dish soap for foam simulation         |
|                                                                |
+----------------------------------------------------------------+
```
